# Peckish

A concept brand by Alinea: a corner fried-chicken burger joint with a five-level hot sauce line. Crispy by nature. Saucy by choice. Peckish by design.

Four responsive pages built from the Figma frames, a sortable sauce range, a heat guide, a data-driven product page and a browser-local demo bag. No real checkout, orders, or payments.

## Hosting

Static HTML, CSS, and JavaScript. No build step. Publish the `main` branch, root folder, using GitHub Pages. All paths are relative, so it works as a project site.

## Files

- `index.html` — homepage (hero, the big seven burgers, the sauce range, philosophy banner)
- `burgers.html` — burger menu plus sides, drinks and kids
- `sauces.html` — all five sauces, the Full Flock 5-pack and the heat guide
- `product.html` — sauce product page; pass `?sauce=chick|hen|rooster|firebird|last-will`
- `styles.css` — design tokens and responsive styling
- `products.js` — concept catalog (sauces, burgers, 5-pack)
- `script.js` — demo bag, sorting, PDP rendering, nav, hero copy rotation
- `*.webp` — optimized burger, bottle and interior photography
- `logo-peckish-*.svg`, `mark-rooster.svg`, `favicon.svg` — brand marks

Typography: Fira Sans and Fira Code via Google Fonts.

## Scope

Menu pricing, sauce descriptions and brand copy are placeholder concept content. The demo bag is stored only in the visitor's browser.

Brand assets are included for this portfolio showcase; no general reuse license is granted.
